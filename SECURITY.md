# Security Policy

## Supported versions

ReadLingo is currently an early-stage project. Security fixes are made against the `main` branch and the latest published development build.

## Reporting a vulnerability

Please do not open a public GitHub issue for credentials, private data, exploitable vulnerabilities or detailed attack steps.

After the repository is created, use GitHub's private vulnerability reporting or contact the repository maintainer through the private contact method listed in the repository profile. Include:

- affected version or commit;
- device model and Android version;
- reproducible steps or a minimal proof of concept;
- impact assessment and any suggested mitigation.

Do not include personal learning data, EPUB files or private dictionaries in a public issue or pull request.

## Scope notes

ReadLingo stores books, settings, vocabulary and study states locally in WebView storage. Do not share exported vocabulary files, IndexedDB data or debug logs that contain personal content when reporting an issue.
